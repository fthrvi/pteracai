# PteracAI

PTE Academic practice that actually teaches you when you get it wrong.
Every mistake comes with a specific explanation, a "common trap" warning,
and a fresh follow-up question generated by an LLM to verify mastery.

**152 questions** across Reading (MCQ, Re-order, Fill-blanks), Listening
(Write From Dictation), and Writing (Summarize Written Text, Essay), plus
**153 PTE-specific tips and tricks** including templates, scoring algorithm
insights, and exam-day tactical hacks.

## How it works

- **Auto-graded tasks** (MCQ, re-order, fill-blanks, dictation) grade
  instantly client-side. No LLM needed.
- **Subjective tasks** (Essay, Summarize Written Text) are graded by an
  LLM against the official PTE rubric.
- **Wrong-answer mastery loop** — when you miss a question, click
  "Get a similar question" and the LLM generates a fresh question testing
  the same skill with different content.

## Self-host (free)

Fork this repo and deploy to Vercel — no env vars needed since each
visitor brings their own key.

```bash
git clone https://github.com/fthrvi/pteracai
cd pteracai
npm install      # installs @anthropic-ai/sdk and openai
vercel           # follow prompts; first deploy gives you a preview URL
vercel --prod    # promote to production
```

Visit your URL → click **Settings** → pick provider → paste key → Save.

## Local development

If you have Claude Code installed (claude.com/claude-code), you can
practice without an API key — Claude Code in your terminal acts as the
LLM, using your existing subscription.

```bash
python3 server.py
# open http://127.0.0.1:5173
```

When the browser shows *"Generating with Claude..."* and the hint appears
after 3 sec, tell Claude Code in your terminal:

> process pending pterac requests

Claude Code reads `data/requests.jsonl`, writes responses to
`data/responses.jsonl`, browser picks it up via polling.

## Privacy

PteracAI is BYOK (bring your own key). Here's exactly what happens to
your key on the deployed version:

1. You paste it in **Settings** → it's stored in your browser's
   `localStorage` (your device only).
2. When you submit an essay or request a follow-up, the key is sent in
   an HTTPS header (`x-api-key`) to the serverless function at
   `/api/request`.
3. The function forwards your prompt + key to the provider you chose
   (Anthropic / OpenAI / OpenRouter), gets the response, returns it
   to your browser.
4. The function never logs or persists your key. Error messages have
   the key string redacted.

The full source of the serverless function is at
[`api/request.js`](api/request.js) — read it to verify.

If you don't trust the hosted demo, **self-host**: fork the repo,
deploy to your own Vercel account, only you (or whoever you share the
URL with) ever interacts with it.

## Architecture

```
public/                        # Vercel serves this at root
├── index.html
├── static/{app.js,styles.css}
└── data/bank.json             # 152 questions + 153 tips
api/
└── request.js                 # Vercel serverless function (BYOK)
data/                          # Local file-bridge (gitignored)
├── requests.jsonl
├── responses.jsonl
└── attempts.jsonl
scripts/import_scraped.py      # Bank import script (one-shot)
server.py                      # Local Python dev server
vercel.json                    # Vercel config
package.json                   # @anthropic-ai/sdk, openai
CLAUDE.md                      # Protocol Claude Code follows locally
```

## Why BYOK?

- **Zero hosting cost.** Vercel hobby tier is free, and there's no
  shared API key to burn through.
- **Privacy.** Your key, your calls, your spend.
- **Provider freedom.** Use whichever model you prefer (or whichever
  has the best price). OpenRouter alone gives access to ~150 models.
- **Forkability.** Anyone can run their own copy with zero
  configuration beyond pasting a key.

## Adding more questions

Edit `public/data/bank.json` directly, or extend
`scripts/import_scraped.py` and run:

```bash
python3 scripts/import_scraped.py
```
