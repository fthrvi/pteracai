# PteracAI

English test prep that actually teaches you when you get it wrong.
Every mistake comes with a specific explanation, a "common trap" warning,
and a fresh follow-up question generated by an LLM to verify mastery.

**~435 questions** across **PTE Academic**, **IELTS Academic**,
**TOEFL iBT**, and the **Duolingo English Test**, plus **~380 test-specific
tips and tricks** including templates, scoring-algorithm insights, and
exam-day tactical hacks.

## How it works

- **Auto-graded tasks** (MCQ, re-order, fill-blanks, dictation,
  true/false, matching headings) grade instantly client-side. No LLM needed.
- **Subjective tasks** (Essay, Summarize Written Text, TOEFL Academic
  Discussion, Duolingo Write About the Topic, Speaking responses) are
  graded by an LLM against the official rubric for each test.
- **Wrong-answer mastery loop** — when you miss a question, click
  "Try a similar one" and the LLM generates a fresh question testing
  the same skill with different content.
- **Mock exams** with realistic timing per section, weak-area-biased
  question selection, pause/resume across sessions, and a full
  question-by-question review at the end.
- **Score-report upload** — drop your last PTE/IELTS/TOEFL/Duolingo
  score report PDF and the LLM builds a tailored improvement plan
  based on your weakest skills.

## Try it

**Live demo:** https://pteracai.vercel.app

You'll need a key from one of:

- **Anthropic** (Claude) — [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)
- **OpenAI** (GPT) — [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
- **OpenRouter** (Claude, GPT, Gemini, Llama, Mistral, and ~150 more via one key) — [openrouter.ai/keys](https://openrouter.ai/keys)

The key stays in your browser. The serverless function uses it to call
the provider, never logs or persists it.

**Don't want to sign up for a paid key?** OpenRouter has a generous free
tier — get a key there and the app will use free models automatically.
This is the recommended path for personal use.

## Self-host (free)

Fork this repo and deploy to Vercel — no env vars needed since each
visitor brings their own key.

```bash
git clone https://github.com/fthrvi/pteracai
cd pteracai
npm install      # installs @anthropic-ai/sdk and openai
vercel           # follow prompts; first deploy gives you a preview URL
vercel --prod    # promote to production
```

Visit your URL → click **Settings** → pick provider → paste key → Save.

## Optional: shared free-tier AI

You can offer visitors a small daily quota of free AI requests so they
can try the app before adding their own key. PteracAI routes free-tier
requests to OpenRouter's `:free` model cascade (gpt-oss-120b,
deepseek-v4-flash, gemma-4-31b) with automatic fallback if one is
rate-limited.

To enable:

1. Sign up free at https://openrouter.ai/ and create an API key.
2. In Vercel: Project → Settings → Environment Variables → add `OPENROUTER_FREE_KEY` with your OpenRouter key.
3. Redeploy: `vercel --prod`.

Visitors now see a "Free AI: 20/20" badge in the topbar and can use the
AI features without configuring anything. After 20 requests/day per
visitor (tracked in their browser's localStorage), they're prompted to
add their own OpenRouter free key.

**Note:** the shared free key has OpenRouter's per-key rate limits
(~200 requests/day across all visitors combined). For hobby / friends
use this works fine. For wider distribution, lower the per-visitor cap
in `app.js` (`FREE_TIER_QUOTA`), or skip the shared tier entirely and
rely on BYOK with documented free-signup paths for each provider.

## Optional: community question bank (Supabase)

PteracAI can save every AI-generated follow-up question to a shared
Postgres so future visitors see those questions too. The bank grows
organically as people practice.

To enable:

1. Sign up free at https://supabase.com/ → create a new project.
2. In the Supabase project: SQL Editor → run the contents of
   [`scripts/supabase_init.sql`](scripts/supabase_init.sql). Creates
   `community_questions` + `tailored_tips` tables with content-hash dedup
   and RLS.
3. Get your project URL and **service_role** key from Settings → API.
4. In Vercel: Project → Settings → Environment Variables, add:
   - `SUPABASE_URL` = your project URL (e.g. `https://xxxx.supabase.co`)
   - `SUPABASE_SERVICE_KEY` = your service_role key (server-side only)
   - `SUPABASE_ANON_KEY` = your anon public key (also fine — used for reads)
5. Redeploy: `vercel --prod`.

Once enabled:
- Every AI-generated follow-up question is silently saved (deduped by
  content hash, anonymous — no user IDs).
- The picker fetches community questions per type alongside the seed
  bank, blending them into random selection.
- Visitors don't need to opt in — they automatically benefit from
  questions other learners have triggered.

**Privacy and moderation:** questions are stored anonymously (no user
ID, no IP). The `community_questions` table has a `hidden` column for
manual moderation via the Supabase dashboard.

## Local development

If you have Claude Code installed (claude.com/claude-code), you can
practice without an API key — Claude Code in your terminal acts as the
LLM, using your existing subscription.

```bash
python3 server.py
# open http://127.0.0.1:5173
```

When the browser shows *"Generating with Claude..."* and the hint appears
after 3 sec, tell Claude Code in your terminal:

> process pending pterac requests

Claude Code reads `data/requests.jsonl`, writes responses to
`data/responses.jsonl`, browser picks it up via polling.

## Privacy

PteracAI is BYOK (bring your own key). Here's exactly what happens to
your key on the deployed version:

1. You paste it in **Settings** → it's stored in your browser's
   `localStorage` (your device only).
2. When you submit an essay or request a follow-up, the key is sent in
   an HTTPS header (`x-api-key`) to the serverless function at
   `/api/request`.
3. The function forwards your prompt + key to the provider you chose
   (Anthropic / OpenAI / OpenRouter), gets the response, returns it
   to your browser.
4. The function never logs or persists your key. Error messages have
   the key string redacted.

The full source of the serverless function is at
[`api/request.js`](api/request.js) — read it to verify.

If you don't trust the hosted demo, **self-host**: fork the repo,
deploy to your own Vercel account, only you (or whoever you share the
URL with) ever interacts with it.

## Cross-device sync (optional)

Sign in with Google to sync your settings, attempt history, mastery
queue, and score profile across devices. Data is stored in a hidden
folder in **your own Google Drive** (`appDataFolder` scope) — the app
owner never sees it.

The hosted demo currently requires the app owner to add your Google
email as a "test user" because the `drive.appdata` scope is treated
by Google as restricted (production verification is a months-long
process for solo projects). **Without sign-in, the app works fully on
this device** — use the **"Continue without signing in"** link on the
landing page. Progress saves to localStorage instead of Drive.

### Set up Google Sign-In on your own fork

One-time, takes about 3 minutes if you only need a few testers; weeks
of verification if you want fully open public sign-up.

1. Go to https://console.cloud.google.com/ and create a project.
2. Enable the **Google Drive API**.
3. Configure the **OAuth consent screen**: External → fill in app name, scopes: `userinfo.email`, `userinfo.profile`, `https://www.googleapis.com/auth/drive.appdata`.
4. Add testers under **Test users** (each email you want to allow during development).
5. Create credentials: OAuth Client ID → **Web application**. Authorized JavaScript origins = your deployed URL(s).
6. Replace `window.PTERACAI_GOOGLE_CLIENT_ID` in `public/index.html` with your Client ID.
7. Commit, push, deploy.

## Adaptive coaching

After 3 consecutive wrong answers on the same task type + topic, a
**Coach Mode** button appears. Clicking it sends the recent attempts
(question + your wrong answer) to your LLM, which:

1. Diagnoses the specific failure pattern (e.g. "you keep matching on
   keywords without checking meaning")
2. Gives targeted micro-tips that quote your actual wrong answers
3. Recommends a drill focus to break the pattern

Uses your existing API key — no extra setup.

## Why BYOK?

- **Zero hosting cost.** Vercel hobby tier is free, and there's no
  shared API key to burn through.
- **Privacy.** Your key, your calls, your spend.
- **Provider freedom.** Use whichever model you prefer (or whichever
  has the best price). OpenRouter alone gives access to ~150 models.
- **Forkability.** Anyone can run their own copy with zero
  configuration beyond pasting a key.

## Adding more questions

Use one of the existing seed scripts as a template (idempotent — re-runs
merge without duplicates):

```bash
python3 scripts/seed_ielts.py
python3 scripts/seed_toefl_duolingo.py
```

Or edit `public/data/bank.json` directly. The v2 schema is
`{schema: 2, tests: {<test_id>: {label, short, tips, questions}}}`.
